## 4. 讨论延伸：车辆质量的影响（来自报告 6.2）

报告通过改变 `Vehicle Dynamics` 中的质量参数，发现：

- **1575 kg（标称）**：正常完成变道；
- **6000 kg（超载）**：横向急动度尖峰 ±3 m/s³（超 ISO2631 阈值），车身摇摆；
- **100 kg（过轻）**：横摆率 18 s 达 -40°/s 极限，19 s 偏航失控。

本 Python 复现版用轴距 `L` 与 `max_accel` 近似体现动力学约束；若要复现质量敏感性，
可将质量 `m` 引入自行车模型的转动惯量项（横摆动力学），观察不同 `m` 下的横向急动度
与末姿态，方法完全可迁移。
